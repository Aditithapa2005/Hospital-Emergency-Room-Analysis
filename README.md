# Hospital Emergency Room Analysis Dashboard (Excel)

##  Project Overview
This project focuses on analyzing Hospital Emergency Room (ER) data using Microsoft Excel to monitor patient visits, waiting times, satisfaction scores, and department referrals.

The interactive dashboard helps stakeholders understand emergency room performance, identify trends, and make data-driven decisions to improve patient services and operational efficiency.

## Project Objectives
- Analyze the total number of patients visiting the emergency room.
- Monitor average patient waiting time.
- Evaluate patient satisfaction scores.
- Analyze patient admission status.
- Understand patient age and gender distribution.
- Identify the most frequently referred departments.
- Measure the percentage of patients attended within 30 minutes.

## Tools & Technologies
- Microsoft Excel
- Power Query (Data Cleaning and Transformation)
- Power Pivot (Data Modeling)
- DAX (Calculated Columns)
- Pivot Tables
- Pivot Charts
- Excel Dashboard & Data Visualization
  
## Key Performance Indicators (KPIs)
Number of Patients: Total patients visiting the emergency room.
Average Wait Time: Average time patients wait to receive medical attention.
Patient Satisfaction Score: Average patient satisfaction score.

## Dashboard Features
Patient Admission Status – Admitted vs. Not Admitted.
Patient Age Distribution – Categorization of patients by age groups.
Timeliness Analysis – Percentage of patients seen within 30 minutes.
Gender Analysis – Distribution of patients by gender.
Department Referrals – Analysis of referrals across different departments.
Daily KPI Trends – Monitoring patient visits, waiting time, and satisfaction scores.

## Project Outcome
This project demonstrates the use of Excel's advanced data analysis and visualization capabilities to transform hospital emergency room data into an interactive dashboard for monitoring key performance indicators and supporting better operational decisions.
